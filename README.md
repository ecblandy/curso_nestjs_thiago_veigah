# Estudos de Backend com NestJS 🚀

Este repositório foi criado com o objetivo de **estudar e praticar desenvolvimento backend utilizando NestJS**, seguindo o conteúdo e a metodologia apresentada no **curso de Backend com NestJS do Thiago Veiga**.

O foco principal é consolidar conceitos fundamentais de backend, arquitetura, boas práticas e padrões utilizados em aplicações profissionais.

---

## 🎯 Objetivo

- Aprender e aprofundar conhecimentos em **NestJS**
- Entender a estrutura de um projeto backend escalável
- Aplicar conceitos de:
  - Arquitetura em camadas
  - Clean Architecture
  - Boas práticas de API REST
  - Injeção de dependência
  - Validações e DTOs
- Criar uma base sólida para evoluir para projetos reais e produção

---

## 🧠 Conteúdos Estudados

- Fundamentos do **NestJS**
- Estrutura de pastas e módulos
- Controllers, Services e Providers
- Dependency Injection
- DTOs e validação de dados
- Pipes, Guards e Interceptors
- Middlewares
- Tratamento de erros
- Boas práticas de organização de código
- Integração com banco de dados (quando aplicável)
- Padrões e conceitos utilizados em backend moderno

---

## 🛠️ Tecnologias Utilizadas

- **Node.js**
- **NestJS**
- **TypeScript**
- **Class Validator / Class Transformer**
- **Banco de Dados**
